# ParmaIdraulica

Sito one-page per il servizio di pronto intervento idraulico H24 a Parma.

## File

- `index.html` — struttura e contenuti della pagina (stile con Tailwind CSS via CDN)
- `script.js` — funzioni interattive: scorrimento ai contatti, notifiche (toast) e chat di assistenza

## Come aprirlo

Apri `index.html` nel browser. Non servono installazioni.
